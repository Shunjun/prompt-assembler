Agent / Skill / 工作流 提示词拼装实验室 — 使用说明
=============================================

这是一个完全离线可用的静态网页，无需安装、无需本地服务器。

打开方式
--------
1. 解压本压缩包（或直接进入 web 目录）。
2. 用浏览器打开同目录下的 index.html：
   - Windows：双击 index.html，或右键 → 打开方式 → Chrome / Edge / Firefox
   - macOS：双击，或拖到浏览器窗口
   - Linux：xdg-open index.html 或直接拖入浏览器
3. 也可从文件管理器将 index.html 拖到地址栏（地址以 file:// 开头即可）。

注意：本页通过 data.js 内嵌全部数据，不依赖 fetch / 网络请求，因此 file:// 协议下可正常使用。
请保持 index.html、styles.css、app.js、data.js 在同一文件夹内。

功能简介
--------
- 左侧：按「全部 / Agent / Skill / 工作流」筛选来源；展开后选择提示词组合
- 「工作流」收录两个开发工作流工具：GitHub Spec Kit（10 条斜杠命令）和 Task Master（A 层 8 类内部提示词 + B 层 Cursor 规则与 3 个子 Agent），各带一条「概览」组合，汇总工作流顺序和读源码发现的问题（标「分析要点」）
- 右侧：查看说明与仓库链接
- 「固定段」与「条件分支」均以卡片展示每一段的完整提示词原文（默认全部展开，可逐段或「全部展开 / 全部收起」），每张卡片可单独复制
- 条件分支卡片标明「何时加入」，用开关决定是否加入；未开启的段落也会以淡色显示原文，方便查看会加入什么
- 实时预览「最终发给 LLM 的提示词」（宽屏时固定在右侧），支持复制全文与字数统计
- 地址栏 # 后为组合 ID，可直接分享某个组合的链接
- 「重置开关」恢复各条件段默认开/关状态

数据说明
--------
内容来自 prompt-lab 的 sources / compositions 中文结构化数据，
为结构忠实的可交互近似，非运行时字节级复现。许可证请遵循各上游仓库。
工作流工具的版本：github/spec-kit commit 1e933c49（MIT）；eyaltoledano/claude-task-master commit c0c98d36（MIT + Commons Clause）。

技术说明
--------
纯静态 HTML/CSS/JS，无外部 CDN、无构建步骤、仅使用系统字体。
