Agent / Skill 提示词拼装实验室 — 使用说明
========================================

这是一个完全离线可用的静态网页，无需安装、无需本地服务器。

打开方式
--------
1. 解压本压缩包（或直接进入 web 目录）。
2. 用浏览器打开同目录下的 index.html：
   - Windows：双击 index.html，或右键 → 打开方式 → Chrome / Edge / Firefox
   - macOS：双击，或拖到浏览器窗口
   - Linux：xdg-open index.html 或直接拖入浏览器
3. 也可从文件管理器将 index.html 拖到地址栏（地址以 file:// 开头即可）。

注意：本页通过 data.js 内嵌全部数据，不依赖 fetch / 网络请求，因此 file:// 协议下可正常使用。
请保持 index.html、styles.css、app.js、data.js 在同一文件夹内。

功能简介
--------
- 左侧：按「全部 / Agent / Skill」筛选来源；展开后选择提示词组合
- 右侧：查看说明与仓库链接；切换「条件分支」开关
- 「固定段」始终包含；可选「展开固定段说明」
- 下方实时预览「最终发给 LLM 的提示词」，支持复制全文与字数统计
- 「重置开关」恢复各条件段默认开/关状态

数据说明
--------
内容来自 prompt-lab 的 sources / compositions 中文结构化数据，
为结构忠实的可交互近似，非运行时字节级复现。许可证请遵循各上游仓库。

技术说明
--------
纯静态 HTML/CSS/JS，无外部 CDN、无构建步骤、仅使用系统字体。
